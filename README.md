# Rules of Survival: Unbound — Website

Coming-soon site for **Rules of Survival: Unbound** — a fan-made preservation/revival project.
Live at: `https://rennware.github.io/ROS-UNBOUND/`

> Fan project. Not affiliated with NetEase. Rules of Survival © NetEase, Inc.

## Structure
```
index.html   — single page (nav · hero · status · story · modes · maps · roadmap · faq · community)
css/         — styles (cobalt palette from the official mark)
js/          — interactions (scrollspy, accordions, counters, ticker…)
assets/      — marks, favicons, og-image (all original project assets)
```

## Local preview
Open `index.html` directly, or:
```powershell
python -m http.server 8080
```

## Editing
Push to `main` — GitHub Pages republishes automatically.
