02 / THE STORY

From the biggest drop
to lights out

  1. 2017

    The first drop

    Rules of Survival lands and drags the battle-royale wave with it — up to 300 players on one island.

  2. 2018

    One of the biggest

    Steam release (App 788260), PC and mobile, millions of survivors. The NeoX client grows into the build we study today.

  3. 2022

    Lights out — 27 June

    Servers shut down. The client still sits on a million drives, talking to nobody. Steam page delisted.

  4. 2026

    Unbound — 11 October

    Day one of preservation. We keep the original bits untouched, learn how they fit, and rebuild the missing half: the server side, named Unbounded.

05 / THE PLAN

Five phases, no shortcuts

Click a phase to see what it means. Order is deliberate — revival work waits for the decode.

Inventory the installer set, hash everything, install the client read-only, map the file tree. Rule one: the original bits never change.

Open the NeoX archives, log every format — meshes, scripts, audio banks, net stubs — into public docs. Old tools first, custom parsers only when they fail.

A localhost server that answers the client's dead calls: patch check, auth stub, matchmaking stubs. The goal is killing the boot errors on 127.0.0.1.

Land, loot and fight on a local server — bots or LAN first, before anyone talks about public matchmaking.

Open it up properly. Announcements, waves and rules all live in Discord when we get there.
