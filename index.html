    04 / INTEL

    What the client gave up

    INT-01

    Two ciphers. That's it.

    The entire game uses none + rotor. No third cipher ever existed — the escalation we feared never happened.

    INT-02

    Rotor key never changed

    Same key since the 32-bit era. One derivation, done forever — every archive fell the same way.

    INT-03

    172,104 hashes

    md5_list handed us a full path → MD5 manifest of the client. Instant integrity oracle for everything we unpack.

    INT-04

    175 endpoints

    Harvested from decrypted scripts — including the plist template. That file is Unbounded's route map.

    INT-05

    UNISDK_LOGIN_JSON

    The client reads a base64 identity blob from the environment. We mint our own — clean-room, no injector hooks.

    INT-06

    The QR lives in the SDK

    qr.mpsdk.easebar.com — the login wall is native UniSDK, not in the game scripts. Hence the fight.

    INT-07

    Cert: accepted

    The launcher trusted our self-signed leaf as-is. No CA ceremony — one less wall between us and the boot.

    INT-08

    Two empty files skip the patcher

    Empty no_patch.txt + no_first_patch.txt → the in-game updater stands down completely.
